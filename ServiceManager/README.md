# 服务管理平台

## 项目概述
本项目是一个用于管理和监控服务的应用程序，采用前后端分离架构。

## 技术栈
- 前端: HTML/CSS/JavaScript
- 后端: Go语言
- 数据库: MySQL

## 功能特性
- 服务卡片展示
- 服务详情弹窗
- 服务管理(添加/修改/删除)
- 数据持久化存储

## 项目结构
```
ServiceManager/
├── frontend/       # 前端代码
├── backend/        # 后端代码
├── docs/           # 项目文档
└── README.md
```

## 快速开始
1. 安装依赖
2. 配置数据库
3. 启动后端服务
4. 访问前端页面
